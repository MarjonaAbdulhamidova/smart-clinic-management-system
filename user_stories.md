# Smart Clinic Management System – User Stories

## 1. Doctor User Stories

- As a Doctor, I want to log in securely so that I can access my personal doctor dashboard.
- As a Doctor, I want to manage my profile so that patients can view my professional information.
- As a Doctor, I want to define my available dates and time slots so that patients can book appointments.
- As a Doctor, I want to view all my scheduled appointments so that I can manage my daily activities.
- As a Doctor, I want to view patient details so that I can prepare for consultations.
- As a Doctor, I want to create and manage prescriptions so that patients receive appropriate treatment information.
- As a Doctor, I want to view my appointment history so that I can track previous consultations.

## 2. Patient User Stories

- As a Patient, I want to register an account so that I can use the clinic management system.
- As a Patient, I want to log in securely so that my personal and medical information remains protected.
- As a Patient, I want to manage my profile so that my contact information stays up to date.
- As a Patient, I want to search for doctors by name and specialty so that I can find the right healthcare professional.
- As a Patient, I want to view doctor availability so that I can select a convenient appointment time.
- As a Patient, I want to book an appointment so that I can schedule a consultation.
- As a Patient, I want to view and cancel my appointments so that I can manage my bookings.
- As a Patient, I want to view my prescriptions so that I can follow my doctor's treatment instructions.

## 3. Admin User Stories

- As an Admin, I want to log in securely so that I can access administrative functions.
- As an Admin, I want to add new doctors so that the clinic can expand its medical staff.
- As an Admin, I want to update doctor information so that the system contains accurate records.
- As an Admin, I want to remove inactive doctor accounts so that the doctor directory remains current.
- As an Admin, I want to view and manage patient accounts so that patient records remain organized.
- As an Admin, I want to view all appointments so that I can monitor clinic activities.
- As an Admin, I want to manage doctor specialties and availability so that appointment scheduling works correctly.
- As an Admin, I want to generate appointment reports so that I can analyze clinic performance.
- As an Admin, I want to manage user access and roles so that system security is maintained.

## 4. General System Requirements

- The system must provide secure authentication and role-based authorization.
- The system must validate user input before saving information.
- The system must prevent conflicting appointment bookings.
- The system must store and retrieve clinic information reliably.
- The system must expose REST APIs for communication between frontend and backend.
